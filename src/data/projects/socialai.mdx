# SocialAI: AI-Powered Social Media Content Generator & Analyzer

## Overview

SocialAI is a modern AI-powered social media platform that allows users to generate content, analyze engagement, explore trending topics, and manage their social media workflow from a single platform.

## What Users Can Do

* **Generate Content:** Create AI-powered social media posts using Google Gemini.
* **Choose Platforms:** Generate content for Twitter, Instagram, LinkedIn, and Facebook.
* **Customize Tone:** Generate content using different tones according to the user's requirements.
* **Analyze Engagement:** View engagement and performance data through interactive charts.
* **Explore Trends:** Discover trending topics and find new content ideas.
* **Schedule Content:** Organize and schedule social media posts.
* **Secure Authentication:** Register and verify accounts using OTP-based email authentication.
* **Manage Sessions:** Secure user sessions using JWT authentication.
* **Manage Content:** Create and manage generated social media content.

## Why I Built This

I built this platform to solve a common problem faced by content creators and social media users — creating consistent, engaging, and platform-specific content takes a lot of time.

SocialAI brings AI content generation, trending topics, engagement analytics, and content management together in one platform.

The main goal was to build a practical full-stack application that demonstrates how generative AI can be integrated into a real-world product.
