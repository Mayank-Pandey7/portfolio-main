## Overview

**Devora** is an AI-powered developer career copilot designed to empower engineers throughout their career journey. It features conversational AI technical mock interviews with instant rubric scoring, automated ATS resume optimization with keyword gap analysis, developer identity passports, and interactive career progression analytics.

## Key Features

* **AI Mock Technical Interviews:** Realistic conversational technical interviews with real-time feedback, grading, and rubric scoring powered by Google Gemini AI.
* **ATS Resume Analyzer:** Detailed parsing, keyword matching against target job descriptions, formatting score, and actionable rewrite recommendations.
* **Developer Identity & Profiles:** Customizable illustrated avatar presets, seniority passports, skill matrix, and career progression stats.
* **Modern Design System:** Responsive champagne, porcelain, and obsidian palette with fluid typography and glassmorphism.
* **Secure Authentication:** User accounts with JWT session management, bcrypt password hashing, and encrypted data storage.
* **Career Performance Dashboard:** Real-time metrics tracking interview performance, resume improvements, and skill progression.

## Tech Stack

* **Frontend:** React, React Router, Lucide Icons, Canvas Confetti, Tailwind CSS, Space Grotesk & Libre Caslon typography
* **Backend:** Node.js, Express.js, MongoDB with Mongoose, JWT authentication, bcryptjs
* **AI Engine:** Google Gemini AI API with fallback heuristic engine
* **Deployment:** Vercel

## Impact & Key Achievements

* Built a full-featured developer career platform combining mock interviews and resume optimization in one cohesive workspace.
* Designed an intelligent prompt pipeline with Google Gemini to generate consistent, rubric-based technical evaluation scores.
* Implemented actionable keyword gap analysis comparing candidate resumes against modern tech stack job requirements.
* Built responsive, accessible UI components with interactive feedback animations.
