## Overview

**Marvel Timeline & Multiverse Explorer** is a state-of-the-art cinematic interactive timeline, character archive, and multiversal relic provenance explorer. It features an interactive spatial canvas spanning all 6 phases across 44 MCU canonical entries (2008–2027), dynamic bezier narrative threads, multiversal Earths catalogue, and comprehensive character and cosmic relics databases.

## Key Features

* **Vertical Sacred Timeline Tree (Earth-616):** Full 6-phase journey across 44 MCU entries rendered on an interactive spatial canvas with pinch-to-zoom, touch drag, and bezier narrative connections.
* **Multiverse Earths Catalogue:** Vertical side spine featuring Earth-616, Earth-838 (Illuminati), Earth-10005 (X-Men / Deadpool), Earth-96283 (Raimi Spider-Verse), and Battleworld (Secret Wars).
* **Cinematic Character Archives:** Detailed profiles for Avengers, Guardians, Mutants (X-Men, Fantastic Four), Thunderbolts*, and Incursion Villains with cross-phase status records.
* **Cosmic Relics & Artifacts Vault:** Complete database of Infinity Stones, Darkhold, Ten Rings, Quantum Bands, and Asgardian/Wakandan armaments with chronological wielder provenance tracks.
* **6-Leaf Flower Dial Selector:** Dark intro scrubber dial with cinematic trailers, movie capsules, and phase telemetry.

## Tech Stack

* **Framework:** Next.js (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS & Custom Spatial Layout Engine
* **Icons:** Lucide React
* **Canvas Engine:** HTML5 2D Canvas Engine
* **Deployment:** Vercel

## Impact & Key Highlights

* Engineered a custom HTML5 canvas graph engine supporting infinite zoom and fluid panning across multi-decade timelines.
* Designed a dark, atmospheric comic-accurate aesthetic with spatial glassmorphism and cinematic sound cues.
* Deployed live on Vercel with responsive touch-gesture support across mobile and desktop viewports.
